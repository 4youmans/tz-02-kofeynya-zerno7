Настройки атрибуции, окно и пользовательское оповещение зафиксировать кадрами реального ресурса.

Три страницы: «Трафик», «Заявки», «Кампании». Источники GA4 и лист leads. Для объединения агрегировать обе стороны до source + campaign (+ date для дневного графика). Период применяется к обеим сторонам. Заявки считать по уникальному request_id; текущие paid не выдавать за оплаты, совершённые за период, если даты оплаты нет.
