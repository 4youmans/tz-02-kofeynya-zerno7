# Неполнота исходного контента

ТЗ требует 20 позиций меню, 6 сортов зерна и 3 карточки преподавателей с опытом, но запрещает добавлять отсутствующие факты. В разделе 2 даны только 5 кофейных напитков, общая цена десертов и минимальная цена зерна. Поэтому опубликованы только известные позиции. Фильтр чая показывает сообщение об уточнении ассортимента. Вместо вымышленных преподавателей — сведения об обучении из ТЗ. В галерее 6 обозначенных иллюстраций, не фотографии класса. Это отклонения от полного состава контента, требующие согласования. Свободные места по потокам не даны: пока используются неизвестные значения, без ложного обещания наличия. Политика допускает только тестовые данные до согласования условий оператором.
