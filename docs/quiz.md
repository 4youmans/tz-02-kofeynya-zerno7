# Правила теста

Четыре вопроса. Каждый ответ добавляет один балл одноимённому направлению: первый — barista_basic, второй — latte_art, третий — alternative, четвёртый — corporate. Побеждает максимальный балл. При равенстве выбирается первое направление по этому порядку. Четыре первых ответа дают barista_basic. Незаполненный тест результата не выдаёт.
